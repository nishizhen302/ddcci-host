## 老化功能 —— 已做成一键（2026-07-10 真机试出，本节留档结论）

早先判断「纯模拟按键宏做不到，因为中间要同时按住左右键」是**错的**：真机上那一步
并不需要双键长按，缺的只是 PDF 没列出的 **OK 键 = 0x04**（靠 GUI「自定义键值」行
逐值试出来）。补上 OK 之后两条宏都是纯按键序列，不用逆向老化工具、不用抓 DDC 线：

- 进工厂菜单 = `Menu → OK`
- 开启老化 = 进工厂菜单后再 `Menu → Menu → Right → Menu → Exit → Exit`
- 键间隔 0.35s（发太快固件丢键）；实现见 `nanwei_core.FACTORY_KEYS / AGING_KEYS`，
  GUI 是 OSD 面板下方两个按钮，CLI 是 `nanwei_cli.py factory|aging`。

因此原计划的「frida hook 老化工具抓命令」整条路线作废。
