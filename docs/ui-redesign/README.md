## 老化功能 — 待逆向的一条命令

需求：显示器有个「老化」功能，进入靠一串 OSD 按键，**中间有一步需要同时按住左右键保持几秒**。
想做成控制台上的一键。

**结论**：纯模拟按键宏做不到——协议的模拟按键（0xC0 帧）只能发单键单击「事件」，
表达不了「两键同时 + 保持」这种物理状态组合。

**改走逆向**：用户手上有那台显示器配套的「老化工具」（能点按钮让显示器进老化），
让工具去发、我们在旁边抓那条命令。

**明天到公司后的步骤**：
1. 提供老化工具的 exe 路径/名字 → 先拆导入表+字符串，判断它走哪条通道
   （标准 DDC / NVAPI / ADL / 串口 / USB 工装）。
2. 据此写 hook 脚本（frida 挂发送函数），点「老化」按钮实时打印发出的字节。
3. 点几次做对照（进老化 / 退老化 / 别的操作）→ diff 拎出「进/退老化」两条命令。
4. 命令加进控制台，做成一键（进老化 + 停止老化）。

前提确认：这个老化工具确实是控制那台显示器、点按钮显示器真会进老化。
若它只发普通 DDC、老化仍靠物理按键，则它没有这条命令，需改抓显示器 DDC 线流量或找厂商要工装命令。
