```python
# phytune/vcp_codes.py
# -*- coding: utf-8 -*-
"""RL6410 调试 VCP 操作码 + 载荷打包/解包(纯函数)。

与固件 UserCommonDdcciDefine.h 的 _DDCCI_OPCODE_DBG_* 一一对应。
DDC/CI 一次 SET VCP 只能带 16bit value, 故地址/数据分别编码。
"""

VCP_ADDR_LATCH = 0xE0   # SET: page<<8|offset 锁存地址; GET: peek 返回当前值
VCP_POKE = 0xE1         # SET: type<<8|data 写入锁存地址
VCP_OVERRIDE = 0xE2     # SET: op<<8|slot 操作 override 表


def pack_addr(page, offset):
    """page+offset -> 16bit 载荷。越界抛 ValueError。"""
    if not (0 <= page <= 0xFF):
        raise ValueError("page 越界: %r" % (page,))
    if not (0 <= offset <= 0xFF):
        raise ValueError("offset 越界: %r" % (offset,))
    return (page << 8) | offset


def unpack_addr(value):
    """16bit 载荷 -> (page, offset)。"""
    return ((value >> 8) & 0xFF, value & 0xFF)


def pack_poke(data, type_=0):
    """data(8bit) + type(0=直接页, 1=data-port) -> 16bit 载荷。"""
    if not (0 <= data <= 0xFF):
        raise ValueError("data 越界: %r" % (data,))
    if type_ not in (0, 1):
        raise ValueError("type 只能 0/1: %r" % (type_,))
    return (type_ << 8) | data
```

```python
# phytune/regaccess.py
# -*- coding: utf-8 -*-
"""具名寄存器访问: 把 peek/poke 翻译成调试 VCP 序列, 跑在任意 Backend 上。"""
from phytune import vcp_codes as vc


class RegAccess:
    """绑定一个 backend + 显示器号, 提供 peek/poke。"""

    def __init__(self, backend, mon_id):
        self._be = backend
        self._mon = int(mon_id)

    def peek(self, page, offset):
        """读 page/offset 处寄存器低字节; 任一步失败返回 None。"""
        if not self._be.set_vcp(self._mon, vc.VCP_ADDR_LATCH,
                                vc.pack_addr(page, offset)):
            return None
        r = self._be.get_vcp(self._mon, vc.VCP_ADDR_LATCH)
        if r is None:
            return None
        return r[0] & 0xFF

    def poke(self, page, offset, data, type_=0):
        """写 data 到 page/offset; 失败返回 False。"""
        if not self._be.set_vcp(self._mon, vc.VCP_ADDR_LATCH,
                                vc.pack_addr(page, offset)):
            return False
        return self._be.set_vcp(self._mon, vc.VCP_POKE,
                                vc.pack_poke(data, type_))
```

```python
    def phytune_peek(self, page, offset, mon_id):

            v = RegAccess(be, int(mon_id)).peek(int(page), int(offset))
```

# P1~P4 阶段路线（开工前各自细化为独立 plan）

> 这几期含大量固件 C（硬件在环）与 UI 交互，细节强依赖 P0 实测（如 ScalerSetByte 分页原语的真实形态、override 表容量、CED 寄存器读法）。故此处只锁交付物与关键文件/接口，每期开工前用 writing-plans 基于上一期结果细化，避免现在写下会被实测推翻的"伪细节"。

## P1：override 表抗重锁

**交付物：** poke 进去的值能扛过信号扰动/重锁。

- 固件新建 `Kernel\Scaler\RL6410_Series_Scaler\Code\RL6410_Series_TMDSDebug.c`：
  `struct { BYTE port; WORD addr; BYTE value; BYTE type; bit active; } g_DebugOverride[24];`
  + `ScalerTMDSDebugApplyOverride(BYTE ucPort)` 遍历应用 port 匹配（或 0xFF 通配）的 active 项。
- 在 `RL6410_Series_TMDSRx2~5.c` 的 `SetDFEInitial_EXINT0 / SetPhy_EXINT0 / InterruptInitial` **末尾**各加 `ScalerTMDSDebugApplyOverride(_Dx_INPUT_PORT);`。
- 固件 SET 0xE2：`op<<8|slot`，op=1 登记（用上次 0xE0 地址 + 0xE1 值 + 当前端口）、op=0 删 slot、op=2 清空。
- 主机：`RegAccess.override_set(slot, page, offset, data, port)` / `override_clear(slot)` / `override_clear_all()` + 对应 `app.Api` 方法 + UI"登记为常驻"按钮。
- **验收：** 登记 DFE override → 手动拔插/换分辨率触发重锁 → peek 确认值仍在。

## P2：参数模型 + 分组 UI + 实时 CED

**交付物：** 命名滑杆调参 + 实时眼质量反馈。

- `phytune/rl6410_params.yaml`：首批=spec §5（频检 `P71_E7/EC/E8-EB`；CDR `P7B_2C/31/2E/2F/32-37`；DFE `P7B_A2/B2/C2`、`A5/B5/C5`、`E0`、`E2-E5`、`E6-EB`），每项 `name/group/page/offset/bitmask/shift/type/range/default/consumed_by/online_needs_override/src_macro`。
- `phytune/params.py`：加载 yaml、位域读改写（peek 整字节→改位域→poke）、范围夹值。TDD（纯逻辑，无硬件）：位域编解码 round-trip、越界拒绝、`src_macro` 唯一性。
- UI `ui/phytune/`：三组（DFE/CDR/频检）命名滑杆+数值+范围+`在线`/`需override`徽章；认 RTK 板（复用 `pick_default_monitor`）。
- **实时 CED 状态条**：轮询 `P71_0B~18` 锁定/错误计数，数字+曲线。先在 P0/P1 板上确认这些计数寄存器的实际读法与清零方式，再实现。
- **验收：** 拉 LE 滑杆，CED 错误计数实时变化；profile 存/取 JSON。

## P3：离线编译出 bin

**交付物：** 调好的参数一键烘焙成可烧 bin。

- 一次性重构：把 spec §5 参数在 `RL6410_Series_TMDSRx2~5.c` 的写死值抽进生成头 `RL6410_DebugTune.h`（`#define`，默认值=原值，行为不变）。四端口引用同名宏。
- `phytune/builder.py`：参数集→渲染 `RL6410_DebugTune.h`→diff 预览→调 `build-rl6432-firmware`/UV4→回显 bin 路径+MD5。TDD：渲染幂等、默认值=原值、diff 正确。
- **验收：** 改一个 DFE 参数→烘焙→编译出 bin→MD5 可复现；不开调试时 bin 与基线一致。

## P4：烧录集成

**交付物：** 产 bin 后可一键调用用户的 ISP 工具烧录。

- `phytune/flasher.json`：命令模板（`cmd/args/port`，`{bin}`/`{port}` 占位），默认空=只产 bin。
- `phytune/flasher.py`：读模板、占位替换、`subprocess` 执行、回显 returncode/输出。TDD：占位替换、空模板时拒绝并提示手动烧。
- UI：bin 产出后出现"一键烧录"按钮（仅当 flasher.json 已配）。
- **验收：** 配好命令后，烘焙→编译→烧录一条龙；命令失败有清晰回显。
